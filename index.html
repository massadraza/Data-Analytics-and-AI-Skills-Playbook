Get started in 3 steps

Designed for Claude Code, but the markdown files work in any AI tool.

1

Clone the repo

Grab all 32 skills locally.

git clone https://github.com/massadraza/\
Data-Analytics-and-AI-Skills-Playbook.git
2

Drop into your project

Copy the skills into .claude/commands/ and, if you want the multi-agent workflows, .claude/workflows/ too.

cp Data-Analytics-and-AI-Skills-Playbook/skills/*.md \
   your-project/.claude/commands/
cp Data-Analytics-and-AI-Skills-Playbook/.claude/workflows/*.js \
   your-project/.claude/workflows/
3

Trigger from your AI

Run one skill as a slash command, or a whole audit as a workflow:

/dataset-health
/eval-report
/feature-importance

Workflow: pr-readiness-check
Workflow: production-readiness-audit
