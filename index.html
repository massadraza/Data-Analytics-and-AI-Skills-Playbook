Works with your AI tool of choice

Each skill is a plain markdown file. Native slash commands in Claude Code; paste-compatible everywhere else.

Claude Code Native

Full slash command integration. Skills live in .claude/commands/.

GitHub Copilot Compatible

Ships native copilot-instructions.md that routes Copilot to the right skill automatically.

Cursor Compatible

Drop skills into .cursor/rules/ or reference them directly in the Cursor chat.

Codex Compatible

Ships an AGENTS.md that points Codex at the right skill for each task.

Windsurf Compatible

Paste any skill file contents directly into Windsurf chat, or add to project rules.

Any chat assistant Compatible

Each skill is plain text. Copy, paste, and run in any AI tool that accepts prompts.

Get started in 3 steps

Skills are slash commands in Claude Code. The same markdown files work in Copilot, Cursor, Codex, and Windsurf without modification.

1

Clone the repo

Grab all 32 skills and 6 workflows locally.

git clone https://github.com/massadraza/Data-Analytics-and-AI-Skills-Playbook.git
git clone https://github.com/massadraza/Data-Analytics-and-AI-Skills-Playbook.git
2

Drop into your project

Claude Code: copy skills to .claude/commands/.
Copilot / Cursor: drop in .github/prompts/ or reference directly in chat. 

cp Data-Analytics-and-AI-Skills-Playbook/skills/*.md your-project/.claude/commands/
Copy-Item Data-Analytics-and-AI-Skills-Playbook\skills\*.md your-project\.claude\commands\
3

Invoke from your assistant

Run a skill as a slash command, or paste the file into any AI chat.

/dataset-health
