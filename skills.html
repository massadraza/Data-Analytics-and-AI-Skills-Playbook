📊 Data Quality & Auditing

Catch problems in your data and pipeline before they reach your model.

/dataset-health Audit

Dataset health check

Audits missing values, class imbalance, temporal gaps, duplicates, outliers, and per-cultivar coverage. Flags anything that could undermine model reliability.

View source →
/data-leakage Audit

Data leakage detector

Scans Python ML files for train/test contamination, future-data leakage, scaler/encoder leakage, and CV-fold leakage. Reports file paths, line numbers, and fixes.

View source →
/feature-audit Audit

Feature inventory audit

Builds a matrix of which features each model uses, flags inconsistencies, collinearity risks, and features that depend on physical sensors vs. weather data alone.

View source →
/temporal-split Audit

Temporal split validator

Audits train/test split strategy for time-series integrity. Detects random splits that leak future data and shows corrected temporal-split code per model.

🎯 Model Evaluation

Understand how your model actually performs — beyond a single accuracy number.

/eval-report Eval

Full evaluation report

Generates classifier metrics (precision, recall, F1, AUC), regressor metrics (RMSE, MAE, R²), per-cultivar breakdown, top failure cases, and calibration check.

View source →
/model-compare Eval

Cross-model comparison

Walks every model folder and builds a comparison table: architecture, features used, metrics, hyperparameters. Flags strongest model and which are experimental.

View source →
/overfitting-check Eval

Overfitting risk scorer

Compares train vs. test gap, checks model complexity and regularization, audits CV strategy. Assigns each model a Low / Medium / High overfitting risk score.

View source →
/feature-importance Eval

Feature importance explainer

Extracts and ranks feature_importances_ or SHAP values, separates Stage 1 vs. Stage 2 drivers, flags redundant or surprising features, checks stability across versions.

⚙️ Tuning & Optimization

Squeeze more performance from a model without retraining from scratch.

/hyperparameter-suggest Tune

Hyperparameter search planner

Proposes a search space, ranks parameter priority, generates ready-to-run Optuna or GridSearchCV code, and recommends the right CV strategy for your data.

View source →
/threshold-tune Tune

Decision threshold tuner

Sweeps the classification threshold across a range, frames the false-negative vs. false-positive cost tradeoff, and recommends an optimal cutoff with justification.

View source →
/cultivar-analysis Tune

Per-cultivar performance analysis

Breaks down model metrics by turfgrass cultivar, identifies most/least susceptible varieties, and decides whether to pool or train separate per-cultivar models.

🚀 Deployment & Explanation

Get models out of notebooks and into production — and explain what they're doing.

/model-to-api Deploy

FastAPI packager

Serializes the model, generates a FastAPI /predict endpoint with Pydantic input validation, response schema, and a ready-to-run curl example.

View source →
/prediction-explainer Explain

Plain-English prediction explainer

For a given set of inputs, explains which features drove the prediction, runs a counterfactual ("what would flip this?"), and flags extrapolation risk — for non-technical readers.

View source →
/new-model Scaffold

New model experiment scaffolder

Creates a new model folder from a template, updates the pipeline for any feature changes, and writes a README describing the experiment and how it differs from prior models.
